📊 Project Name: Job Market Analyzer & Career Advisor (Streamlit App)
🧠 AI Resume Analysis: Uses Groq API to analyze resumes, extract skills, experience, and give smart career insights.
🔍 Skill Gap Detection: Identifies missing skills and suggests what to improve for better job opportunities.
💼 Job Recommendations: Integrates Adzuna API + RapidAPI to fetch real-time job listings based on role, skills, and location.
🎯 Career Guidance: Suggests suitable job roles, career paths, and in-demand skills based on user profile.
🌍 Live Job Search: Provides updated job openings from multiple job platforms.
🎨 User-Friendly UI: Built using Streamlit with custom CSS for a clean, modern dashboard experience.
🔐 Secure Setup: API keys are stored safely using .env file for security.
🚀 Final Outcome: A smart AI-powered career assistant that helps users improve resumes and find relevant jobs easily.
